# Body distraction controlled comparison

User authorized implementation of several directions together, following the investigation plan. Implement four independent arms: existing coverage25 baseline; 3x sampling weight for usable, known positive body windows with H unavailable; 0.3 probability of removing complete face-dependent evidence in body training windows with O/HO remaining; coverage25 with a two-slot head gap. These are candidate settings, not validated improvements.

Use the same immutable caches, training-only normalizer, seed, epochs and batch size. The sampling arm draws the original number of windows with replacement; increased weight changes expected frequency, not epoch length. Dropout is label-independent and train-only; clear F and FO values/masks/quality/eligibility, which also removes H and gaze evidence. Preserve O/HO and labels; existing loss availability rules remove unsupported supervision. Preserve legacy behavior when the optional experiment configuration is absent. Capture existing CPU torch RNG and loader generator states for exact resume.

Provide pretraining train/val evidence audits and an orchestrator that generates validated per-arm configs, runs train and best/last diagnostics in isolated sequential processes, and updates a comparison report after each completed checkpoint. Device memory is not shared between simultaneous runs. Failures retain logs and completed results. An explicit continuation may skip only verified completed phases; do not silently overwrite a partially trained run. Report fixed-threshold body/face performance, H strata, all-known-positive detection fraction and gaze/other task regressions. Do not auto-select a winner or claim validation results are held-out generalization.

Test mask semantics, train-only selection, excluded unknown/unavailable windows, exact resume, baseline compatibility, config validation and a synthetic end-to-end suite. No new perception model or production cache is introduced in this comparison.
