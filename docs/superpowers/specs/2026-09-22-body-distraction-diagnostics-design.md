# Body 分心逐窗口诊断

用户已确认：生成 body 分心错误诊断表，定位低召回原因，再决定感知、特征或训练调整。本次在现有 model 工作区实现离线工具，不改变训练、标签、模型或可用性规则。

输入为可信联合训练 checkpoint（含校验文件）和原训练 manifest/特征根目录。默认诊断 val/body/distraction；可选择 face 或 all 作为对照。复用 WindowDataset 与 checkpoint normalizer，校验完整数据指纹，禁止重新拟合归一化或静默切换数据。支持 CPU/CUDA/NPU，默认 CPU。

输出到全新目录：windows.csv（全部选中窗口）、summary.json（完成标记与指标）。每行包含 recording_id/view/subject、相对视频首个解码帧的窗口起止秒、末槽标签、概率、TP/FP/TN/FN/unknown/unavailable、原始与最终头姿/虹膜有效率、四组资格/质量和分心门控权重。原始视频路径不在 manifest，故通过 recording_id 与 view 定位，不猜测路径。

统计须保留未知与不可用计数，按 F 组资格、受试者和录制分组。分心正例在全部已知标签中的检出比例和有效输入覆盖率与训练口径指标同时报告。阈值表仅供分析，不自动选阈值、不修改配置。F 组未通过时给出机械条件原因，不宣称因果根因。

验证使用真实 CPU 模型、可信合成 checkpoint 和特征缓存，覆盖时间索引、批处理一致性、未知/不可用、头姿有效但 F 被过滤、过期特征、数据指纹拒绝、输出目录拒绝覆盖。服务器真实缓存不在本机，交付命令供用户运行，不声称已定位真实根因。
