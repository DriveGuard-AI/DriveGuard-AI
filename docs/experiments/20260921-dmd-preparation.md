- `docs/training/DMD_PREPARATION.md`：正式 CLI、当前边界和后续批量特征/manifest 接线。

## 审核修复

独立规格审核发现：明确哈欠与未知哈欠类型重叠时不应直接采信同一轴的正例。补充回归测试后修正；持续闭眼仍可独立提供正例。源帧时间同时增加 signed-int64 范围检查。

独立质量审核还发现：合法 int64 范围内的巨大 PTS 跳变仍可能导致稠密槽列表耗尽内存。因此标签转换增加每录制 100,000 槽的分配前容量检查，超过限制直接报错，不截断或伪造时间。

测试使用自行编写的小型标注与不可解码占位视频，确认准备 CLI 不调用视频解码或依赖 ML 包。所有输出写入测试临时目录，原始数据不进入 Git。
