本清单只收录**已经发现、尚未解决或不打算在当前阶段解决**的限制。它回答三个问题：
这个问题是什么、会造成什么后果、证据在哪里。已修复的缺陷不在此重复，见文末的追溯表。

判定依据一律是可重跑的实测，不接受"看起来没问题"。新增条目请补上证据与状态，

## 如何新增条目

1. 先在 `docs/experiments/` 留下可重跑的实测记录，写清命令、数据与判定；
2. 在本表加一行，填上后果与证据链接；
3. 状态要么是"待评估/待样本/受硬件限制"，要么是"设计如此，不修"——不要留空；
4. 问题解决后从"未解决"移到"已解决"，并补提交号。
