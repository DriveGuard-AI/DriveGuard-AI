# DMD 批量感知到 NPU 训练输入实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans，按 TDD 分步实施并独立审核。

**Goal:** 把已生成的 preparation 清单接到真实视频感知、1000 ms 疲劳代理监督、可恢复缓存及可训练 v2 manifest。

**Architecture:** 复用 run_video，增加可选源帧观察回调，不改旧导出语义。每个 job 生成独占 attempt 目录，完成标记最后发布；不覆盖原始未标注数组。配置、源码、依赖版本、视频和标注 hash 一致时才复用。单独 publish 命令检查所有选中任务并调用 FeatureCorpus 的监督检查，失败不发布 manifest。

**Tech Stack:** Python 标准库 CLI/配置，NumPy 数组，现有 PyAV/YOLOX/MediaPipe 感知环境；现有 NPU 训练入口不改。

用户已批准总体执行方案与 1000 ms 参数。继续在用户指定的 model 分支工作，不建新分支、不推送。没有服务器连接，不宣称本机替服务器完成真实提取。

## 文件及任务

- [x] `inference/perception/video.py`：run_video 可选 frame_observer；完整源帧先经过回调再进入25Hz抽样，保留资源关闭行为。测试真实适配/导出配合现有外部API假件，断言所有原始PTS被记录。
- [x] `training/dmd/batch_config.py`：生成 pilot/all 两种 job 选择，默认 pilot 按 split/subset/view 各选一段，排除未映射 gaze。配置用每job归一化ROI和显式confirmed_exclusive=false；阈值1000、CPU感知工件配置。验证hash、身份、划分、路径、参数。
- [x] `training/dmd/batch.py`：init/run/publish CLI；run按选中任务顺序运行、输出源帧PTS、标签数组、质量统计、失败报告；记录级续跑保留所有失败attempt，无递归删除。输出不在Dataset内；使用独占运行锁，异常退出释放，强制终止后不自动抢锁。
- [x] `training/dmd/cache.py`：校验来源/配置/代码/依赖指纹与完成标记、全部数组hash；run仅复用一致结果，不根据目录存在判定成功。publish引用已验证缓存，按原被试划分，验证输入与标签资格；新目录原子发布。
- [x] `configs/perception/dmd_cpu.json`：已核实三个本地工件的固定hash/source，CPU感知；YOLOX权重许可仍保留pending_permission。
- [x] `configs/dmd/labels.v1.json` 与 prepare：1000ms成为用户确认的首轮默认值，允许显式覆盖，旧preparation中null由batch配置显式替代并记录来源。
- [x] `tests/test_dmd_batch*.py`：RED→GREEN，覆盖PTS/标签对齐、阈值默认、任务筛选、跨主体泄漏、ROI未确认拒绝、缓存损坏/源变更/配置变更拒复用、失败恢复、发布监督不足不成功；生成的小fixture使用真实FeatureCorpus接线，并跑CPU短程训练。
- [x] 文档同步：完整服务器命令、感知/NPU环境分离、pilot扩大all的缓存复用、明确剩余ROI确认和无真实精度声明；全套测试与独立审核。

接口：`run_video(..., frame_observer=None)`；`init_config(preparation_path, output_path, selection='pilot')`；`run_batch(config_path, dataset_root, output_dir)`；`publish_batch(config_path, dataset_root, output_dir, training_config)`。CLI分别使用 `python -m training.dmd.batch init|run|publish`。

运行目录含 `records/<job_id>/<attempt_id>/features/record.json`（原始无标签缓存）、`source_pts_ms.npy`、`targets.npy`、`label_masks.npy`、`complete.json`。发布目录 `manifests/<release_id>/manifest.json` 指向输出根目录下相对.npy路径；manifest不存在表示不可训练。所有阶段都不自动启动长时服务器训练。
