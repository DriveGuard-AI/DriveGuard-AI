# DriveGuard AI v0.1.0 Desktop（Windows）发布说明

状态：**候选发布，待 Windows 实机验收**。本文描述 v0.1 桌面版的范围与交付物，
不表示已经在 Windows 上完成安装/长稳验证。

## 1. 这是什么

一个 Windows x64 桌面安装包：内置后端、前端、Python 运行时；用户不需要安装
Python/Node/数据库，也不需要配置环境变量。模型服务地址与 Token 在构建时内置，
默认打开即连接。

## 2. 包含功能

- 实时监控：风险等级、四任务、六参数判决表、WebSocket、摄像头预览。
- 离线分析：上传视频、服务端抽帧、任务进度/取消、回放与证据时间轴。
- 事件历史：筛选、分页、详情；数据持久化在本地 SQLite。
- 系统设置：摄像头序号/分辨率、预览开关/帧率/连接数、事件保留天数。
- 鉴权：启动时生成随机本地管理 Token，由桌面桥接注入页面。

## 3. 明确不包含

- 统计分析页（v0.2）。
- 多用户/RBAC、多会话/多摄像头。
- 事件视频片段、告警音/外部通知。
- 模型权重、CANN/NPU 运行时；`live` 模式连接外部模型服务。
- Docker、macOS/Linux 安装包、自动更新、代码签名。

## 4. 交付物

```text
DriveGuardAI-Setup-0.1.0.exe
DriveGuardAI-0.1.0-portable.exe
SHA256SUMS.txt
```

安装器为每用户安装，创建桌面/开始菜单快捷方式；数据在
`%APPDATA%\DriveGuardAI`，卸载默认保留。

推送 `v0.1.0` tag 后，`Windows Desktop Release` 工作流会构建并创建一个
**draft GitHub Release**，附两个 exe 与 SHA256；需要人工在 Windows 验收后发布。

## 5. 使用前置条件

- Windows 10/11 x64。
- 能通过 HTTPS 访问构建时内置的模型服务。
- 允许应用使用摄像头（Windows 首次弹窗）。
- 模型服务侧 Token 有效；当前服务单活动会话，多用户同时使用会冲突。

## 7. 已知限制

- `demo` 模式是脚本化回放，六参数为空，不能当模型结论。
- 模型候选包未经真实场景精度验收；`drinking` 存在已知误报（KL-01）。
- body gaze 标记 `unvalidated_body_view`；不能作为注视结论。
- 4 秒预热、NPU 约 8Hz；公网 RTT 高时有效帧率下降。
- 桌面版公网默认 **640×480 / JPEG q60**；手机、饮水等小目标精度需用该分辨率重新验收。
- 完全内置 Token 可被提取；只应使用专用、可轮换、权限受限的 Token。

## 8. 回滚

保留上一版安装包与 SHA256；安装器覆盖安装前先备份
`%APPDATA%\DriveGuardAI\driveguard.db`。回滚时卸载当前版本、恢复数据库、安装旧版。
